# Gymble API & Chatbot

This is the Hugging Face Docker Space for the Gymble backend, containing:
1. Flask API for Food Image and Barcode Analysis
2. FastAPI Chatbot with RAG

Dependencies and weights are downloaded securely on boot from Google Drive.
Make sure to specify `OPENROUTER_API_KEY` in your Space's Secrets!
